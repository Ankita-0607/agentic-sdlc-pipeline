# sample-service

A deliberately small TypeScript library that tracks laboratory samples through
a sequencing workflow (received → sequencing → analysis → review → reported)
and computes turnaround time.

It exists so the pipeline has something realistic to work on: real types, real
tests, and room for the kind of small feature and bug-fix issues a team files
every week. The data model is invented for this demo.

```bash
npm run test:sample    # from the repository root
```
